# Android Capacitor APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wrap the existing Seadio PWA into a Capacitor 7 Android shell, ship a sideloadable debug APK that loads the PWA, talks to a LAN backend (http://NOTEBOOK-IP:8080), and keeps audio playing when the screen locks or the app is backgrounded.

**Architecture:**
- Capacitor 7 wraps `pwa/` as the WebView root (`webDir: 'pwa'`).
- Default backend is unset; on first run we detect `window.Capacitor` and force the existing `⚙ server` dialog open so the user enters `http://192.168.x.y:8080`.
- Cleartext HTTP is allowed only for RFC1918 LAN ranges via a Network Security Config; the rest of the world stays HTTPS-only.
- A minimal in-house Kotlin Capacitor plugin (`SeadioMedia`) starts a Foreground Service with an ongoing notification when JS calls `start()`, so the WebView's audio element keeps playing in the background. JS calls `start()` on `audio.play` and `stop()` on `audio.pause/ended`.

**Tech Stack:**
- Capacitor 7 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`)
- Android Gradle Plugin 8.x + Kotlin
- Android SDK 36 (already installed at `~/Library/Android/sdk`)
- Adoptium JDK 25 (already installed; fall back to JDK 21 via SDKMAN if AGP rejects it)

**Files (new or modified):**
- Create: `capacitor.config.ts`

## Task 3: Network Security Config (cleartext for LAN only)

**Files:**
- Create: `android/app/src/main/res/xml/network_security_config.xml`
- Modify: `android/app/src/main/AndroidManifest.xml`

- [ ] **Step 1: Write the network security config**

Create `android/app/src/main/res/xml/network_security_config.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<network-security-config>
    <!-- Cleartext HTTP only for RFC1918 private ranges (LAN dev). -->
    <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="false">10.0.0.0</domain>
        <domain includeSubdomains="false">172.16.0.0</domain>
        <domain includeSubdomains="false">192.168.0.0</domain>
        <domain includeSubdomains="false">localhost</domain>
        <domain includeSubdomains="false">127.0.0.1</domain>
    </domain-config>
    <!-- Capacitor itself serves the bundled web layer over http://localhost; the line above already covers it. -->
    <base-config cleartextTrafficPermitted="false">
        <trust-anchors>
            <certificates src="system"/>
        </trust-anchors>
    </base-config>
</network-security-config>
```

Note: Android NSC matches the literal host string after DNS — so for IPs you need to enumerate or use `domain` with the exact IP. The block above covers `192.168.0.0` literal hostname only. For a full LAN-wide allowlist, switch to one of the following: (a) keep `cleartext: true` in capacitor.config.ts plus `android:usesCleartextTraffic="true"` in the manifest (broad), or (b) restrict the manifest to NSC and write helper docs telling the user to add their `192.168.X.Y` to the domain-config list.

For MVP simplicity, we use the **broad** approach in the manifest (Step 2) and skip per-IP NSC enforcement. The XML file above is still created and wired up so we can tighten later without restructuring.

## Task 4: First-run server config gate in the PWA

**Files:**
- Modify: `pwa/index.html`

- [ ] **Step 1: Auto-open the ⚙ settings dialog on Capacitor cold start**

In `pwa/index.html`, locate the Settings dialog script (the IIFE at the end that wires `seadio-settings-open`). Replace its inner `(function () { ... })();` body with a version that also auto-opens once when `window.Capacitor` is present and no override is saved yet. The full new IIFE:

```html
<script>
  (function () {
    const dlg = document.getElementById('seadio-settings');
    const input = document.getElementById('seadio-settings-url');
    const form = document.getElementById('seadio-settings-form');
    const openBtn = document.getElementById('seadio-settings-open');

    function openDialog() {
      input.value = (localStorage.getItem('seadio:server-base') || '');
      if (typeof dlg.showModal === 'function') dlg.showModal();
      else dlg.setAttribute('open', '');
    }

    openBtn.addEventListener('click', openDialog);

    form.addEventListener('submit', (e) => {
      const btn = e.submitter;
      if (!btn || btn.value !== 'save') return;
      const v = (input.value || '').trim();
      if (!v) window.SeadioConfig.clearServerBase();
      else window.SeadioConfig.setServerBase(v);
      location.reload();
    });

    // First-run inside a Capacitor shell: force the user to pick a backend.
    const inCapacitor = !!(window.Capacitor && window.Capacitor.isNativePlatform && window.Capacitor.isNativePlatform());
    const hasOverride = !!(localStorage.getItem('seadio:server-base') || '').trim();
    if (inCapacitor && !hasOverride) {
      window.addEventListener('DOMContentLoaded', openDialog, { once: true });
    }
  })();
</script>
```

(Keep the dialog + button markup above this script untouched.)

- [ ] **Step 1: Write the service**

Create `android/app/src/main/java/com/seadio/fm/SeadioMediaService.kt`:

```kotlin
package com.seadio.fm

import android.app.Notification
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.app.Service
import android.content.Context
import android.content.Intent
import android.os.Build
import android.os.IBinder
import androidx.core.app.NotificationCompat

class SeadioMediaService : Service() {

    override fun onBind(intent: Intent?): IBinder? = null

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val channelId = "seadio_playback"
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val nm = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
            if (nm.getNotificationChannel(channelId) == null) {
                val ch = NotificationChannel(
                    channelId,
                    "Seadio playback",
                    NotificationManager.IMPORTANCE_LOW
                )
                ch.setShowBadge(false)
                nm.createNotificationChannel(ch)
            }
        }

        val launchIntent = packageManager.getLaunchIntentForPackage(packageName)
        val pendingFlag = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M)
            PendingIntent.FLAG_IMMUTABLE else 0
        val tap = PendingIntent.getActivity(this, 0, launchIntent, pendingFlag)

        val notif: Notification = NotificationCompat.Builder(this, channelId)
            .setSmallIcon(android.R.drawable.ic_media_play)
            .setContentTitle("Seadio FM")
            .setContentText("Playing in background")
            .setOngoing(true)
            .setContentIntent(tap)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build()

        startForeground(NOTIF_ID, notif)
        return START_STICKY
    }

    override fun onDestroy() {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N)
            stopForeground(STOP_FOREGROUND_REMOVE)
        else
            @Suppress("DEPRECATION") stopForeground(true)
        super.onDestroy()
    }

    companion object {
        const val NOTIF_ID = 7301
    }
}
```

- [ ] **Step 2: Write the plugin**

Create `android/app/src/main/java/com/seadio/fm/SeadioMediaPlugin.kt`:

```kotlin
package com.seadio.fm

import android.content.Intent
import android.os.Build
import com.getcapacitor.JSObject
import com.getcapacitor.Plugin
import com.getcapacitor.PluginCall
import com.getcapacitor.PluginMethod
import com.getcapacitor.annotation.CapacitorPlugin

@CapacitorPlugin(name = "SeadioMedia")
class SeadioMediaPlugin : Plugin() {

    @PluginMethod
    fun start(call: PluginCall) {
        val ctx = context
        val intent = Intent(ctx, SeadioMediaService::class.java)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O)
            ctx.startForegroundService(intent)
        else
            ctx.startService(intent)
        val r = JSObject(); r.put("started", true); call.resolve(r)
    }

    @PluginMethod
    fun stop(call: PluginCall) {
        context.stopService(Intent(context, SeadioMediaService::class.java))
        val r = JSObject(); r.put("stopped", true); call.resolve(r)
    }
}
```

## Task 6: PWA → SeadioMedia bridge

**Files:**
- Modify: `pwa/index.html`

- [ ] **Step 1: Hook ttsAudio + musicAudio play/pause to the plugin**

The PWA already has two audio elements: `ttsAudio` and `musicAudio` (search `pwa/index.html` for `getElementById('ttsAudio')` and `getElementById('musicAudio')`). At the very end of `pwa/index.html`, just before `</body>`, add this script:

```html
<script>
  (function () {
    if (!(window.Capacitor && window.Capacitor.isNativePlatform && window.Capacitor.isNativePlatform())) return;
    const plugin = window.Capacitor.Plugins && window.Capacitor.Plugins.SeadioMedia;
    if (!plugin) return;

    let active = 0;
    const arm = (el) => {
      if (!el) return;
      el.addEventListener('play',  () => { if (active++ === 0) plugin.start().catch(() => {}); });
      const release = () => { if (active > 0 && --active === 0) plugin.stop().catch(() => {}); };
      el.addEventListener('pause', release);
      el.addEventListener('ended', release);
      el.addEventListener('error', release);
    };
    arm(document.getElementById('ttsAudio'));
    arm(document.getElementById('musicAudio'));
  })();
</script>
```

This is intentionally tiny: the existing PWA owns audio scheduling, so we just count concurrent plays and keep the foreground service alive while ≥1 audio is playing.
