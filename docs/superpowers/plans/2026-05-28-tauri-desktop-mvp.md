# Tauri Desktop MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a macOS `.app` of Seadio FM that a non-technical user can double-click. It launches without external dependencies, embeds the existing PWA, and lets the user log into Netease via an in-app QR window.

**Architecture:** Tauri 2.x Rust shell wraps two Node sidecars produced by `@yao-pkg/pkg`: (1) the existing `server.js` (Express + WebSocket, port 8080), (2) NeteaseCloudMusicApi (port 3000). Tauri spawns both at startup, waits for `:8080` to become healthy, then loads `http://127.0.0.1:8080` in the main WebView. Writable state (SQLite DB, TTS cache, Netease cookie) is relocated from the repo root to the OS user-data dir.

**Tech Stack:** Tauri 2.x, Rust 1.95 (stable), Node 22 runtime (bundled by pkg), `@yao-pkg/pkg`, `better-sqlite3` (prebuilt arm64), existing project deps (Express, ws, dotenv, node-cron, openai).

**MVP Done Condition:**
1. Finder double-click on `Seadio.app` launches the app cold (no terminal, no system Node required).
2. The PWA renders in the main window and the WebSocket status indicator is green.
3. Clicking "Login to Netease" opens a second window with a working QR code. Scanning it in the Netease mobile app persists a cookie that survives an app restart.
4. With a real `DEEPSEEK_API_KEY` + `VOLCENGINE_TTS_API_KEY` set via the in-app Settings page, the user can press play and hear a DJ intro followed by one song.
5. Closing the window leaves a tray icon; clicking it restores the window. Quit kills both sidecars.

**Out of scope (deferred to Week 6):** Windows build, code signing, notarization, auto-updater, installer DMG polish.

```js
const path = require('path');
const os = require('os');
const fs = require('fs');

function platformUserDataDir() {
  const appName = 'Seadio';
  if (process.platform === 'darwin') {
    return path.join(os.homedir(), 'Library', 'Application Support', appName);
  }
  if (process.platform === 'win32') {
    return path.join(process.env.APPDATA || path.join(os.homedir(), 'AppData', 'Roaming'), appName);
  }
  return path.join(process.env.XDG_DATA_HOME || path.join(os.homedir(), '.local', 'share'), appName);
}

const userDataDir = platformUserDataDir();
const sqlitePath = path.join(userDataDir, 'claudio.sqlite');
const ttsCacheDir = path.join(userDataDir, 'cache', 'tts');
const neteaseDataDir = path.join(userDataDir, 'netease');

for (const dir of [userDataDir, ttsCacheDir, neteaseDataDir]) {
  fs.mkdirSync(dir, { recursive: true });
}

// resourceDir() returns the read-only root containing pwa/, user/, prompts/.
// In dev, this is __dirname of the caller (i.e. the repo root via require parent).
// When packaged by pkg, process.pkg is set and bundled assets live next to process.execPath.
function resourceDir() {
  if (process.pkg) return path.dirname(process.execPath);
  return path.resolve(__dirname);
}

module.exports = {
  userDataDir,
  sqlitePath,
  ttsCacheDir,
  neteaseDataDir,
  resourceDir,
};
```

- [ ] **Step 2: Create `src-tauri/src/sidecar.rs`**

```rust
use std::time::{Duration, Instant};
use tauri::{AppHandle, Manager};
use tauri_plugin_shell::ShellExt;
use tauri_plugin_shell::process::CommandEvent;

pub async fn start_sidecars(app: &AppHandle) -> Result<(), String> {
    // 1. Netease sidecar on 127.0.0.1:3000
    spawn_named(app, "netease-api", vec![("PORT", "3000"), ("HOST", "127.0.0.1")])?;

    // 2. Seadio server on 127.0.0.1:8080
    spawn_named(app, "seadio-server", vec![("PORT", "8080")])?;

    // 3. Wait for the main server to become reachable.
    wait_for_http("http://127.0.0.1:8080/", Duration::from_secs(30))
        .await
        .map_err(|e| format!("server never became healthy: {e}"))?;
    Ok(())
}

fn spawn_named(app: &AppHandle, name: &str, env: Vec<(&str, &str)>) -> Result<(), String> {
    let mut cmd = app
        .shell()
        .sidecar(name)
        .map_err(|e| format!("sidecar({name}) lookup failed: {e}"))?;
    for (k, v) in env {
        cmd = cmd.env(k, v);
    }
    let (mut rx, _child) = cmd
        .spawn()
        .map_err(|e| format!("sidecar({name}) spawn failed: {e}"))?;

    let label = name.to_string();
    tauri::async_runtime::spawn(async move {
        while let Some(event) = rx.recv().await {
            match event {
                CommandEvent::Stdout(line) => {
                    println!("[{label}] {}", String::from_utf8_lossy(&line));
                }
                CommandEvent::Stderr(line) => {
                    eprintln!("[{label}] {}", String::from_utf8_lossy(&line));
                }
                CommandEvent::Error(err) => eprintln!("[{label}] error: {err}"),
                CommandEvent::Terminated(payload) => {
                    eprintln!("[{label}] exited: {:?}", payload);
                    break;
                }
                _ => {}
            }
        }
    });
    Ok(())
}

async fn wait_for_http(url: &str, timeout: Duration) -> Result<(), String> {
    let started = Instant::now();
    loop {
        let url_owned = url.to_string();
        let ok = tokio::task::spawn_blocking(move || {
            reqwest::blocking::Client::builder()
                .timeout(Duration::from_millis(500))
                .build()
                .map_err(|e| e.to_string())
                .and_then(|c| c.get(&url_owned).send().map_err(|e| e.to_string()))
                .map(|r| r.status().is_success() || r.status().is_client_error())
                .unwrap_or(false)
        })
        .await
        .unwrap_or(false);
        if ok {
            return Ok(());
        }
        if started.elapsed() > timeout {
            return Err(format!("timeout after {:?}", timeout));
        }
        tokio::time::sleep(Duration::from_millis(400)).await;
    }
}
```

```rust
use tauri::{AppHandle, Manager, WebviewUrl, WebviewWindowBuilder};

#[tauri::command]
pub fn open_netease_qr(app: AppHandle) -> Result<(), String> {
    if let Some(existing) = app.get_webview_window("netease-qr") {
        let _ = existing.set_focus();
        return Ok(());

    let url = WebviewUrl::External(
        "http://127.0.0.1:8080/netease/qr-login"
            .parse()
            .map_err(|e: url::ParseError| e.to_string())?,

    WebviewWindowBuilder::new(&app, "netease-qr", url)
        .title("Netease Login")
        .inner_size(360.0, 480.0)
        .resizable(false)
        .build()
        .map_err(|e| e.to_string())?;
    Ok(())
}
```

Replace `main.rs` with:

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod sidecar;
mod qr_window;

use tauri::{
    menu::{Menu, MenuItem},
    tray::{TrayIconBuilder, MouseButton, MouseButtonState, TrayIconEvent},
    Manager, WindowEvent,
};

fn main() {
    tauri::Builder::default()
        .plugin(tauri_plugin_shell::init())
        .invoke_handler(tauri::generate_handler![qr_window::open_netease_qr])
        .setup(|app| {
            // Sidecars
            let handle = app.handle().clone();
            tauri::async_runtime::spawn(async move {
                if let Err(e) = sidecar::start_sidecars(&handle).await {
                    eprintln!("[setup] sidecar start failed: {e}");
                }
            });

            // Tray
            let quit_item = MenuItem::with_id(app, "quit", "Quit Seadio", true, None::<&str>)?;
            let show_item = MenuItem::with_id(app, "show", "Show window", true, None::<&str>)?;
            let menu = Menu::with_items(app, &[&show_item, &quit_item])?;

            let _tray = TrayIconBuilder::new()
                .menu(&menu)
                .on_menu_event(|app, event| match event.id().as_ref() {
                    "quit" => app.exit(0),
                    "show" => {
                        if let Some(w) = app.get_webview_window("main") {
                            let _ = w.show();
                            let _ = w.set_focus();
                        }
                    }
                    _ => {}
                })
                .on_tray_icon_event(|tray, event| {
                    if let TrayIconEvent::Click { button: MouseButton::Left, button_state: MouseButtonState::Up, .. } = event {
                        let app = tray.app_handle();
                        if let Some(w) = app.get_webview_window("main") {
                            let _ = w.show();
                            let _ = w.set_focus();
                        }
                    }
                })
                .build(app)?;

            Ok(())
        })
        .on_window_event(|window, event| {
            if let WindowEvent::CloseRequested { api, .. } = event {
                // Hide instead of quitting on red-button close.
                let _ = window.hide();
                api.prevent_close();
            }
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

## Known Risks / Open Questions

1. **pkg + better-sqlite3 on Node 22**: The fallback in Task 5 Step 7 should handle most cases. If it still fails, the escape hatch is to skip `pkg` for `server.js` and instead bundle a real Node binary as a Tauri resource + `cp -r node_modules` into the resource dir. Cost: ~1 day rework, app size +60 MB.

2. **`scheduler.js` cron triggers DJ at intervals**: If keys aren't set, the cron tries to call DeepSeek and logs errors. Acceptable noise for MVP. Filed for a follow-up "graceful degradation" task in Week 6.

3. **`yt-dlp`**: Not bundled. If `MUSIC_PROVIDER=auto` and Netease misses, the code shells out to `yt-dlp` and will fail with `ENOENT`. Caught by `music-yt-dlp.js`'s try/catch. Acceptable for MVP. Bundling yt-dlp adds ~30 MB; deferred.

4. **Code signing**: Bundle is ad-hoc signed. On first launch macOS shows the "developer cannot be verified" Gatekeeper dialog. User must right-click → Open the first time. This is documented as expected MVP behavior; proper Developer ID signing is in Week 6.
